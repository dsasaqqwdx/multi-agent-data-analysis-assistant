#  Agentic Data Intelligence Platform

An AI-powered multi-agent application for analyzing uploaded CSV datasets.

## Features

-  Data Analysis Agent
-  Data Visualization
-  Machine Learning Agent
-  RAG Agent using ChromaDB
-  Tools Agent
-  LangGraph Supervisor
-  Short-Term Memory
-  CSV Dataset Upload

## Architecture

User
↓
Streamlit
↓
LangGraph Supervisor
↓
Data Agent | ML Agent | RAG Agent | Tools Agent

## Technologies Used

- Python
- Streamlit
- LangChain
- LangGraph
- ChromaDB
- HuggingFace Embeddings
- Scikit-learn
- Pandas
- Matplotlib
